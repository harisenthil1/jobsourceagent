#AI job-source agent

##This is essentially a web-research agent.

The input is a LinkedIn job listing. From that listing, the program will:

LinkedIn job URL
      ↓
Extract company name
      ↓
Find official company website
      ↓
Find official careers page
      ↓
Find one actual open position
      ↓
Return:
company name
careers page URL
job-posting URL
